# Disco Code 🪩

A neon-disco block-coding editor that runs *inside* Scratch: categories, a block palette,
drag-and-drop scripts, editable inputs, C-blocks, a mini stage with a sprite (Groovy), pen,
sounds, green flag / stop, Turbo Mode — all built from Scratch blocks.

**Upload:** scratch.mit.edu → Create → File → *Load from your computer* → `disco-code.sb3` → Share.

**Rebuild:** `pip install numpy && python3 build.py`

## How to use
- Drag blocks from the palette into the script under **when 🏁 clicked**; drag them back to delete.
- Click a number/text bubble to edit it. Click a palette block to try it once.
- 🏁 or click the hat block (or press space) to run, 🛑 to stop. Arrows scroll; 🗑 clears the script.
- Drag Groovy around the stage.

## Secrets (spoilers!)
- Click the **disco ball** → party mode (light beams, music, color-cycling UI).
- Type **D-I-S-C-O** → unlocks the hidden **Disco** category: boogie, spin, moonwalk, rainbow.
- Press **T** → Turbo Mode.
- Click Groovy without dragging → a random dance quip and a spin.
